# Site des Journées D3IA

Site construit automatiquement par GitHub Pages (Jekyll).

## Quel fichier modifier ?

| Je veux modifier…              | Fichier                 |
|--------------------------------|-------------------------|
| La page d'accueil              | `index.html`            |
| L'appel à communications       | `appel.html`            |
| Le programme                   | `_data/programme.yml`   |
| La page d'inscription          | `inscription.html`      |
| Le projet D3TIP                | `projet.html`           |
| Les infos pratiques            | `infos.html`            |
| Le contact                     | `contact.html`          |
| Le menu (toutes les pages)     | `_data/menu.yml`        |
| Les logos de l'accueil         | `_includes/logos.html`  |
| Le pied de page                | `_includes/pied.html`   |
| Les couleurs et la mise en page| `css/style.css`         |

Les images sont dans `images/`, les PDF dans `documents/`.
